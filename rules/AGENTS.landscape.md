# Flisk landscape repository

This repository is a Flisk project, example or starter. Use the shared guidance at <https://github.com/flisk-sh/flisk-skills> when a task matches a published skill.

## Working rules

- Treat each `service.json` as the source of truth for its resource.
- Do not edit generated `.autogenerated/` files by hand. Change their inputs and regenerate them with Flisk.
- Run `flisk doctor` before diagnosing or starting a landscape; resolve reported project configuration errors first.
- Use `flisk networks` to find service URLs. For browser or service-to-service access, use the routed hostname rather than `localhost:<port>`.
- Keep changes scoped to the requested service or stack, and follow the repository's existing scripts and conventions.

## Starting work

Check the repository README for its intended stacks and startup command. Start only the stack needed for the task, for example `flisk up <stack>`; do not assume every project uses the same stack names.
