# TDK (local development)

- TDK is local only. It runs a Docker + Tilt inner loop and does not deploy.
- Run `tdk doctor`, then `tdk up`, from the project root.
- Do not invent Kubernetes manifests or Docker Compose files.

## Skills

Each skill is a folder under `skills/` with a `SKILL.md`:

- `skills/tdk-doctor/SKILL.md`: check or repair the environment and project config before `tdk up`.
- `skills/tdk-troubleshoot/SKILL.md`: diagnose a failed `tdk up`, Docker or Tilt session.
- `skills/layer-autoresearch/SKILL.md`: contributor experiment loop for the L1-L4 Docker layers.
- `skills/tdk-scaffold/SKILL.md`: scaffold new backends, frontends, agents and MCP servers.
- `skills/tdk-generated-files/SKILL.md`: understand and manage `.autogenerated/` files and drift.
- `skills/tdk-agents/SKILL.md`: run AI agents + MCP tools + database in one local stack.
- `skills/tdk-data/SKILL.md`: reset, seed and snapshot local Postgres data.
- `skills/tdk-benchmark/SKILL.md`: measure container scale, idle memory and start times.
- `skills/tdk-ports/SKILL.md`: port selection, Traefik routing and localhost URLs.
- `skills/tdk-upgrade/SKILL.md`: upgrade the CLI and handle generated-file drift.
- `skills/tdk-byo/SKILL.md`: bring-your-own resources and existing services.
- `skills/tdk-secrets/SKILL.md`: project `.env`, params and secrets.
- `skills/tdk-layout/SKILL.md`: multi-repo layouts and ownership patterns.
- `skills/tdk-helm/SKILL.md`: use TDK locally alongside Helm for production.
- `skills/tdk-frontend/SKILL.md`: frontend scaffolding and generated Vite/nginx configs.
- `skills/tdk-python/SKILL.md`: Python backend services.
- `skills/tdk-ui/SKILL.md`: interactive terminal dashboard (`tdk ui`).
- `skills/tdk-dry-run/SKILL.md`: preview stacks with `tdk up --dry-run`.

If your tool does not load skills automatically, read the relevant `SKILL.md` directly.
