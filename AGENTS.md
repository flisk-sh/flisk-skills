# Flisk (local development)

- Flisk is local only. It runs a Docker + Tilt inner loop and does not deploy.
- Run `flisk doctor`, then `flisk up`, from the project root.
- Do not invent Kubernetes manifests or Docker Compose files.

## Skills

Each skill is a folder under `skills/` with a `SKILL.md`:

- `skills/flisk-doctor/SKILL.md`: check or repair the environment and project config before `flisk up`.
- `skills/flisk-troubleshoot/SKILL.md`: diagnose a failed `flisk up`, Docker or Tilt session.
- `skills/layer-autoresearch/SKILL.md`: contributor experiment loop for the L1-L4 Docker layers.
- `skills/flisk-scaffold/SKILL.md`: scaffold new backends, frontends, agents and MCP servers.
- `skills/flisk-generated-files/SKILL.md`: understand and manage `.autogenerated/` files and drift.
- `skills/flisk-agents/SKILL.md`: run AI agents + MCP tools + database in one local stack.
- `skills/flisk-ai-agent-build/SKILL.md`: scaffold a complete local agent system (agent + MCP + DB + queue).
- `skills/flisk-data/SKILL.md`: reset, seed and snapshot local Postgres data.
- `skills/flisk-databases/SKILL.md`: work with Postgres, Prisma, Drizzle, Atlas, Dbmate.
- `skills/flisk-benchmark/SKILL.md`: measure container scale, idle memory and start times.
- `skills/flisk-ports/SKILL.md`: port selection, Traefik routing and localhost URLs.
- `skills/flisk-upgrade/SKILL.md`: upgrade the CLI and handle generated-file drift.
- `skills/flisk-byo/SKILL.md`: bring-your-own resources and existing services.
- `skills/flisk-secrets/SKILL.md`: project `.env`, params and secrets.
- `skills/flisk-layout/SKILL.md`: multi-repo layouts and ownership patterns.
- `skills/flisk-helm/SKILL.md`: use Flisk locally alongside Helm for production.
- `skills/flisk-deploy-alongside/SKILL.md`: work with Helm, Argo CD, Kustomize and cloud hosts.
- `skills/flisk-deploy-aws/SKILL.md`: complete separate skill — deploy to AWS.
- `skills/flisk-deploy-vercel/SKILL.md`: complete separate skill — deploy to Vercel.
- `skills/flisk-deploy-gcp/SKILL.md`: complete separate skill — deploy to Google Cloud.
- `skills/flisk-deploy-azure/SKILL.md`: complete separate skill — deploy to Azure.
- `skills/flisk-deploy-railway/SKILL.md`: complete separate skill — deploy to Railway.
- `skills/flisk-deploy-fly/SKILL.md`: complete separate skill — deploy to Fly.io.
- `skills/flisk-deploy-render/SKILL.md`: complete separate skill — deploy to Render.
- `skills/flisk-frontend/SKILL.md`: frontend scaffolding and generated Vite/nginx configs.
- `skills/flisk-python/SKILL.md`: Python backend services.
- `skills/flisk-build-runtimes/SKILL.md`: Bun, Node, Python, Go, Rust, React, Vue, Svelte, Elysia, Fastify, NestJS.

- `skills/flisk-contributing/SKILL.md`: guide for contributors working on flisk.

If your tool does not load skills automatically, read the relevant `SKILL.md` directly.
