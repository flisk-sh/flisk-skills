# Deploy to AWS

Flisk is local-only. This skill covers taking a validated local stack to AWS.

## Workflow

1. Confirm the stack works locally: `flisk doctor && flisk up <stack>`.
2. Extract the contract from `service.json` files (ports, dependencies, health checks, env).
3. Choose the AWS target:
   - ECS/Fargate or EKS for container services
   - App Runner for simpler web services
   - Lambda + API Gateway for serverless
4. Generate or adapt production artifacts (Dockerfile, task definition, Helm chart, or CDK/Terraform) from the service.json — do not use the local `.autogenerated/` files.
5. Set secrets via AWS Secrets Manager or Parameter Store.
6. Deploy and verify health endpoints.

## Guardrails

- Never deploy the local Traefik/Tilt generated files.
- Keep production config separate from local service.json.
- Test the production image locally first if possible.
