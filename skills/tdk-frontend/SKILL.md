# Frontend services

TDK scaffolds frontends and generates local serving and API client wiring.

## Workflow

1. `tdk resource storefront-web --type frontend --stack shop --yes`
2. Application code lives in the service directory; generated files go under `.autogenerated/` (nginx, Dockerfile, vite.config, tsconfig, api-client.ts).
3. `tdk up shop` serves it behind Traefik.
4. Edit service.json for ports, dependencies or build settings; regenerate as needed.

## Guardrails

- Do not hand-edit the generated nginx or Vite configs.
- See the example of what TDK writes for a frontend in the main CLI README.
