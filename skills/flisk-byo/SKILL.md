# Bring-your-own resources

Integrate existing services via a service.json contract without full scaffolding.

## Workflow

1. Create a directory under `services/<stack>/<name>/`.
2. Write a minimal `service.json` describing type, ports, health checks and dependencies.
3. Place your Dockerfile or use an existing image.
4. Run `tdk doctor` and `tdk up <stack>`.
5. See docs/byo.md in flisk for the supported patterns.

## Guardrails

- Prefer the official scaffolders when possible for consistent generated files.
- Generated wiring still applies; do not hand-edit .autogenerated/.
- Test health checks so Tilt and Traefik treat the service correctly.
