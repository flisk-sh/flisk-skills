# service.json contract

Every resource is defined by one service.json. Flisk generates the local runtime from it.

## Workflow

1. Locate the file under `services/<stack>/<name>/service.json`.
2. Edit only the contract fields (type, dependencies, ports, health, features).
3. Run `flisk doctor` to validate.
4. Regenerate with `flisk resource` or let `flisk up` pick up changes.
5. See the service schema in flisk (`engine/schemas/service-schema.json`).

## Guardrails

- Never hand-edit generated files under `.autogenerated/`.
- Prefer the scaffolders for new services so the schema is satisfied.
